## 9. Guide d'activation

### 9.1 GitHub Student Pack (priorité #1)

**Étapes :**
1. Créer compte GitHub : https://github.com/signup
2. Postuler GitHub Education : https://education.github.com/pack/jour
3. Choisir méthode vérification :
   - **Option A** : Email institutionnel (plus rapide)
   - **Option B** : Uploader carte étudiante / certificat de scolarité
4. Attendre vérification (quelques minutes à 48h)
5. Accéder aux avantages : https://education.github.com/pack/offers

**Conseils :**
- Utiliser email institutionnel si possible (vérification instantanée)
- Prendre photo claire des documents si upload manuel
- Renouveler chaque année avant expiration

### 9.2 Azure for Students

**Étapes :**
1. Aller sur https://azure.microsoft.com/free/students/
2. Cliquer "Start free"
3. Se connecter avec compte Microsoft (ou en créer un)
4. Vérifier statut étudiant avec email institutionnel
5. Activer les crédits ($100) et services gratuits

**Note :** Azure for Students inclut aussi GitHub Copilot gratuit

### 9.3 JetBrains

**Étapes :**
1. Aller sur https://www.jetbrains.com/community/education/
2. Cliquer "Apply now"
