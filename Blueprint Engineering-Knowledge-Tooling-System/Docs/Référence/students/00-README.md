## Labels de confiance (utilisés partout)

| Label | Sens |
|---|---|
| **[V]** | URL vérifiée HTTP 200 le 5 oct. 2026 |
| **[V⚠]** | site vivant mais protégé anti-bot (403/429) — non vérifié par script |
| **[W]** | source Web 2026 citée |
| **[?]** | **à vérifier à la source** — jamais présenté comme un fait |

## Règles permanentes appliquées
- Aucun prix, durée ou condition affirmé sans source.
- "Accessible gratuitement" ≠ "libre d'usage commercial".
- Aucune exhaustivité revendiquée : **"Catalogue partiellement accessible avec les outils disponibles"**.
- Les offres étudiantes peuvent changer — toujours vérifier sur le site officiel.
- L'éligibilité varie selon les pays et les institutions.

## Comment utiliser ce catalogue

### Si vous êtes étudiant
1. Consultez [[12-student-plans]] pour une vue d'ensemble
2. Identifiez les services pertinents pour votre domaine
3. Vérifiez l'éligibilité dans [[14-student-africa]] (si Afrique)
4. Consultez [[13-student-catalog]] pour les détails et liens
5. Inscrivez-vous avec votre email étudiant ou carte

### Si vous formez des étudiants
1. Partagez [[12-student-plans]] avec vos étudiants
2. Utilisez `catalogue-student.csv` pour filtrer par catégorie
3. Vérifiez les conditions de vérification pour votre institution
4. Guidez vos étudiants dans le processus d'inscription
