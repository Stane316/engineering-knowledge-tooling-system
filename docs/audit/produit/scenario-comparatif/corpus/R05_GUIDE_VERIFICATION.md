# R05 — Guide synthétique de vérification

Statut : mémo de travail rédigé pour le scénario, et non copie d'un guide externe ; révision fictive : 2026-10-23. Il décrit une méthode de contrôle, pas un audit exécuté.

Pour un contrôle de formulaire, vérifier le nom accessible calculé, le sens de l'étiquette, l'utilisation au clavier et les messages d'erreur dans les états pertinents. Une règle automatique n'évalue pas seule l'expérience complète.

Pour le texte normal, utiliser le critère de contraste applicable, notamment 4,5:1 pour WCAG 2.2 niveau AA lorsque les conditions du critère 1.4.3 s'appliquent ; les exceptions doivent être examinées dans le contexte. Vérifier avec les couleurs effectivement rendues et documenter la méthode.

INP et FID ne sont pas interchangeables ; des données manquantes doivent rester indiquées comme manquantes. Une seule mesure de laboratoire ne suffit pas à caractériser une expérience de terrain.

Références externes indicatives, non consultées par un agent pendant le test hors ligne : https://www.w3.org/TR/WCAG22/#contrast-minimum et https://web.dev/articles/inp. Avant une utilisation hors exercice, consulter et dater les sources originales.
