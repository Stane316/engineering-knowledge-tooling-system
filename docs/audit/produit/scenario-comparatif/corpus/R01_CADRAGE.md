# R01 — Projet fictif : cadrage

Statut : document synthétique créé pour une expérience EKTS ; ne décrit aucune personne ni site réel. Révision fictive : 2026-10-20.

Le site fictif « Atelier Orbe » est un portfolio francophone présentant cinq projets. Son objectif prioritaire est de permettre à un visiteur de comprendre les services proposés puis d'utiliser le formulaire de contact. Ce n'est pas un blog. Les pages concernées par le scénario sont la page d'accueil et la page de contact.

Contraintes : une personne dispose de cinq jours ouvrés pour préparer des corrections ; aucune modification du site réel ou fictif n'est demandée dans cet exercice. Les recommandations doivent être rédigées en français et accompagnées de critères de vérification. Une proposition d'allonger un article de blog à 600 mots ne peut pas être justifiée uniquement par ce cadrage.
