# Engineering Knowledge Tooling System (EKTS)

Système personnel d'ingénierie augmenté par l'IA.

## 🎯 Objectif

Capitaliser les connaissances techniques, inspecter des sites web, analyser les performances et générer des rapports intelligents.

## 🚀 Démarrage rapide

```bash
git clone https://github.com/[username]/engineering-knowledge-tooling-system.git
cd engineering-knowledge-tooling-system
npm install
npm run dev
```
